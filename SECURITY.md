# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in Mooze, please report it
privately to [dev@mooze.app](mailto:dev@mooze.app).

Please do not disclose vulnerabilities in public issues, pull requests, or other
public channels before they have been addressed.

To help us investigate, include the following where possible:

- A description of the vulnerability and its potential impact.
- The affected version, platform, or component.
- Steps to reproduce the issue or a minimal proof of concept.
- Relevant logs or screenshots, with secrets and personal data removed.

Thank you for helping keep Mooze and its users safe.
